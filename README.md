# P2PHub

Децентрализованное приложение для обмена **сообщениями и файлами** напрямую
между пользователями (peer-to-peer), без центрального сервера. Работает как
обычный сайт в браузере и устанавливается на телефон (Android и iPhone) как
приложение — **без Mac**.

> Статус проекта: 🟡 этап документации. Кода пока нет — сначала договариваемся,
> что и как строим.

## Что это будет уметь (простыми словами)

- Открыл сайт → можешь отправить файл другому человеку **напрямую**, файл не
  лежит ни на каком сервере.
- Можешь переписываться в чате, и сообщения тоже идут напрямую между устройствами.
- Сайт можно «установить» на телефон одной кнопкой («Добавить на главный экран»).
- Позже — выложить в Google Play и App Store.

## Как это вообще возможно без сервера?

Файлы передаются по технологии **WebTorrent** — это торрент прямо в браузере.
Когда ты раздаёшь файл, другой человек скачивает его кусочками напрямую у тебя
(и у других, кто уже скачал). Сообщения идут по **WebRTC** — это прямое
соединение между двумя браузерами.

Подробнее — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Как сайт станет приложением на телефоне (без Mac)

1. Делаем обычный сайт (HTML/CSS/JS).
2. Добавляем два файла — `manifest.json` и `service-worker.js`. Сайт становится
   **PWA** (его уже можно ставить на любой телефон через браузер).
3. Для магазинов используем **PWABuilder** — он сам собирает пакеты для Android
   и iPhone. Сборку для iPhone делаем в облаке (GitHub Actions), Mac не нужен.

Подробный план — в [docs/ROADMAP.md](docs/ROADMAP.md).
