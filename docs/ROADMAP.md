# Дорожная карта (Roadmap) P2PHub

> Незнакомые слова — в [GLOSSARY.md](GLOSSARY.md). Устройство системы — в
> [ARCHITECTURE.md](ARCHITECTURE.md).

Пошаговый план: от пустого проекта до приложения в магазинах. Каждый этап
завершён, когда выполнены все пункты-галочки. Идём строго по порядку — каждый
этап опирается на предыдущий.

## Этап 1 — Простой сайт (каркас)

**Цель:** просто страница в браузере, без P2P.

- [ ] `index.html` — одна страница с заголовком и заглушками экранов
- [ ] `style.css` — базовое оформление
- [ ] `app.js` — пустой, для будущей логики
- [ ] Проверить, что открывается в браузере

**Как проверить:** открыл файл — видишь страницу. Всё.

---

## Этап 2 — Превращаем в PWA (ставится на телефон)

**Цель:** сайт можно установить на Android и iPhone.

- [ ] `manifest.json` — имя, иконки, цвета
- [ ] Иконки приложения (несколько размеров)
- [ ] `service-worker.js` — кэширование, работа офлайн
- [ ] Выложить на бесплатный хостинг (GitHub Pages / Netlify) — нужен HTTPS
- [ ] Проверить «Добавить на главный экран» на реальном телефоне

**Как проверить:** зашёл с телефона → появилась кнопка установки → иконка на
рабочем столе.

---

## Этап 3 — Передача файлов (WebTorrent)

**Цель:** отправить файл с одного устройства на другое напрямую.

- [ ] Подключить библиотеку WebTorrent
- [ ] Кнопка «Поделиться файлом» → получаем magnet-ссылку
- [ ] Поле «Вставить ссылку» → скачивание файла
- [ ] Показать прогресс загрузки
- [ ] Проверить передачу между двумя устройствами

**Как проверить:** на телефоне A выбрал файл, ссылку открыл на ноутбуке B,
файл скачался.

---

## Этап 4 — Сообщения (WebRTC)

**Цель:** живой чат напрямую между пирами.

- [ ] Подключить WebRTC + публичный signaling
- [ ] Установить соединение между двумя пирами
- [ ] Отправка/приём текста
- [ ] Сохранять историю чата локально (в браузере)

**Как проверить:** два устройства переписываются в реальном времени.

---

## Этап 5 — Улучшения (после рабочей версии)

Берёмся, только когда базовое всё работает:

- [ ] Свой signaling-сервер (меньше зависимости от чужих) — см. [SERVERS.md](SERVERS.md)
- [ ] Push-уведомления, когда приложение закрыто — см. [NOTIFICATIONS.md](NOTIFICATIONS.md)
- [ ] Своё железо: **Raspberry Pi**, затем кластер из нескольких Pi на **k3s**
      (лёгкий Kubernetes) для отказоустойчивости — см. [SERVERS.md](SERVERS.md)
- [ ] Сквозное шифрование сообщений (E2E)
- [ ] Офлайн-доставка сообщений
- [ ] Группы / групповые чаты
- [ ] Поиск и список контактов

---

## Правила работы (чтобы не запутаться)

1. **Один этап за раз.** Не прыгаем вперёд.
2. **Каждый этап заканчивается коммитом** в git с понятным описанием.
3. **Сначала самое простое, что работает**, потом красота и оптимизация.
4. Непонятное слово → сразу в [GLOSSARY.md](GLOSSARY.md).
